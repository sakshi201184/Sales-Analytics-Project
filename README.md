# Sales Analytics Project

## Project Overview
This is a Final Data Analytics Project based on sales data.
The project analyzes sales, profit, quantity, categories, regions and customer segments.

## Problem Statement
The purpose of this project is to analyze sales data and identify important trends, patterns and business insights that can help in better decision-making.

## Dataset Description
The dataset contains sales transaction records with information such as:
- Order ID
- Order Date
- City
- Region
- Segment
- Category
- Sub-Category
- Quantity
- Unit Price
- Discount
- Sales
- Profit

## Tools Used
- Microsoft Excel
- Python
- Power BI
- Git
- GitHub

## Data Cleaning
The dataset is inspected for:
- Missing values
- Duplicate records
- Incorrect data
- Data types

Missing values and duplicate records are handled before analysis.

## Exploratory Data Analysis
EDA is performed to understand:
- Total Sales
- Total Profit
- Total Quantity
- Sales by Category
- Sales by Region
- Monthly Sales Trends
- Correlation between numerical variables
- Outliers

## Data Visualization
The project includes:
1. Monthly Sales Trend
2. Sales by Category
3. Sales by Region
4. Profit by Category
5. Top Products

## Power BI Dashboard
An interactive Power BI dashboard is created with:
- Total Sales KPI
- Total Profit KPI
- Total Orders KPI
- Sales Trend
- Category Analysis
- Regional Analysis
- Profit Analysis
- Slicers and Filters

## Key Insights
The major findings from the analysis are documented based on sales, profit, category and regional performance.

## Business Recommendations
Data-driven recommendations are provided to improve sales performance, profitability and business decision-making.

## Conclusion
The Sales Analytics Project demonstrates an end-to-end data analytics process including data preparation, EDA, visualization, Power BI dashboard creation and business insights.
